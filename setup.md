# Setup Project Task List

1. Populate the README.md file with content describing the project, whihc is a C++ solution to this leetcode problem: https://leetcode.com/problems/score-of-a-string/description/
1. Create a src directory
1. Create a test directory
1. Populate the test directory with a google test based unit test for the source directory - it should run the tests described in the leetcode problem description
1. Create a CMakeLists.txt file in the root directory that builds the project
1. Run the tests using CMake and Google Test
1. Verify the tests fail because no code has been written yet
1. Write the code to solve the problem
1. Run the tests again to verify they pass
1. Populate the .vsode/tasks.json file with a task to build the project using CMake
1. Populate the .vscode/launch.json file with a task to run the tests using CMake
